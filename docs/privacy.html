UNZIP (압축 해제) · 시행일 2026-11-26

수집하는 정보

UNZIP은 개인정보를 수집, 저장, 전송하지 않습니다. 앱은 인터넷에 연결하지 않으며 분석, 광고, 추적 도구가 없습니다.

파일 처리

압축 파일은 사용자가 선택하거나 끌어놓은 것만 사용자의 Mac 안에서 처리합니다. 파일 내용과 파일 이름은 어디로도 전송되지 않습니다. 설정(저장 위치, 인코딩 등)은 사용자의 Mac에만 저장됩니다.

폴더 접근

압축을 풀거나 만들 폴더에 쓰기 위해 macOS가 사용자에게 폴더 접근 허락을 묻습니다. 허락한 폴더는 앱이 다음 실행에서도 쓸 수 있게 Mac 안에만 기억합니다.
